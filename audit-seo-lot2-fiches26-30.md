## Règles appliquées

1. `<title>` : aucune modification nécessaire (toutes < 60 chars, incluant nom produit + 'L\'établ\'IA')
2. `<meta description>` : toutes réécrites pour tenir dans 120-160 chars, orientées bénéfice client
3. OG tags complets ajoutés : og:title, og:description, og:image (etabli.svg), og:type=product, og:url, og:site_name
4. Twitter Card ajoutée : summary_large_image
5. Canonical ajoutée pointant vers l'URL principale https://letablia.fr/produits/{slug}.html
6. Bloc SEO inséré en début de `<head>`, avant `<meta charset="utf-8"/>` — cohérent avec le pattern lot2 fiches 21-25
