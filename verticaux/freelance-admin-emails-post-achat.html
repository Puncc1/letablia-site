Le client après la mission : la relation qui se construit ou se perd

Une mission terminée est une relation qui peut rebondir — ou s'arrêter définitivement. Ce qui fait la différence, c'est souvent ce qui se passe dans les deux semaines suivant la livraison du travail.

Un freelance qui envoie un message de suivi sincère 5 jours après la livraison — "Comment se passe l'intégration de [livrable X] ?" — est celui dont le client se souvient quand il a un nouveau besoin.

Ce qu'un suivi post-mission contient pour un freelance

  • J0 — Livraison : confirmation de livraison avec les éléments clés, point de contact pour les questions.
  • J5 — Suivi : "Comment ça se passe avec [le livrable] ?" Message court, sincère.
  • J14 — Témoignage : invitation à partager un avis ou témoignage, si la relation est bonne.
