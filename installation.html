Trouver mon système

Guide d'installation

Installer un système forgé en 5 minutes, sans compétence technique.

⚙️ Avant de commencer

  • ✓ Un compte n8n (Cloud ou Auto-hébergé). Créer un compte gratuit n8n
  • ✓ Le fichier JSON téléchargé depuis votre email de confirmation
  • ✓ Le guide PDF fourni avec votre achat
  • ✓ 5 minutes de disponibilité

Étape 1 : Se connecter à n8n

  1. Allez sur app.n8n.cloud (ou votre instance n8n)
  2. Connectez-vous avec vos identifiants
  3. Vous arrivez sur le tableau de bord « Workflows »

Étape 2 : Importer le fichier JSON

  1. Cliquez sur le bouton « + New » en haut à gauche
  2. Sélectionnez « Import »
  3. Téléchargez le fichier JSON reçu par email
  4. Nommez votre workflow (ex: « Relances clients »)
  5. Cliquez sur « Import »

Étape 3 : Configurer les intégrations

Votre système forgé peut intégrer plusieurs services (Gmail, Slack, Zapier, etc.). Selon votre système :

  1. Double-cliquez sur chaque nœud rouge (non configuré)
  2. Connectez votre compte à n8n en cliquant sur « Authenticate »
  3. Autorisez les permissions demandées
  4. Remplissez les paramètres spécifiques (ex: nom du dossier Dropbox, ID Notion, etc.)
  5. Sauvegardez chaque modification

💡 Conseil : Consultez le guide PDF pour les détails des intégrations spécifiques à votre système.

Étape 4 : Tester le workflow

  1. Cliquez sur le bouton « Test workflow » en bas à droite
  2. Vérifiez que tous les nœuds passent au vert
  3. Si un nœud reste rouge, consultez l'erreur et rectifiez la configuration
  4. Si tout est au vert, passez à l'étape 5

Étape 5 : Activer et déployer

  1. Cliquez sur le bouton « Save » en haut
  2. Cliquez sur le curseur « Off » pour « On » (activer le workflow)
  3. Votre système est maintenant actif et s'exécutera selon son calendrier programmé

⚠️ Problèmes courants

« Erreur d'authentification »

Vérifiez que vous avez autorisé n8n à accéder à votre compte. Supprimez la connexion et recommencez.

« Le fichier JSON ne s'importe pas »

Vérifiez que le fichier a l'extension .json et qu'il n'a pas été renommé.

« Le workflow s'arrête avec une erreur »

Consultez les logs en cliquant sur la nœud avec le point d'exclamation. Le guide PDF explique les solutions courantes.
