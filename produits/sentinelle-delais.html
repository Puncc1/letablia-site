Le problème que vous connaissez

Une deadline oubliée. Un client qui perd confiance.

Quand vous gérez cinq projets en parallèle, la mémorisation manuelle des échéances ne suffit pas. Un livrable rendu deux jours après la date convenue parce que vous étiez sur un autre dossier, et la relation client en porte les traces longtemps.

Les outils de gestion de projet complexes exigent que tout le monde soit dans le même outil. Vous travaillez seul ou en petite équipe, depuis un tableur. Vous n'avez pas besoin d'un outil de plus — vous avez besoin d'une sentinelle.

Ce que le système forgé fait
  • ✓Lit chaque matin toutes vos échéances ouvertes dans le tableur
  • ✓Envoie des alertes différenciées selon le temps restant (J-14, J-7, J-3)
  • ✓Marque les alertes envoyées — jamais deux fois la même
  • ✓Cesse d'alerter dès que vous clôturez la tâche (statut "closed")

Une seule alerte par palier. Pas de harcèlement quotidien. Le système surveille discrètement et vous parle uniquement quand c'est utile.

Questions fréquentes

Avant d'acheter.

Est-ce que je reçois une alerte chaque jour jusqu'à la deadline ? +

Non. Vous recevez une alerte par palier : une à J-14, une à J-7, une à J-3. Pas de harcèlement quotidien. Si vous clôturez la tâche dans le tableur (statut "closed"), plus aucune alerte n'est envoyée.

Et si ma deadline tombe un dimanche ? +

Le système calcule les jours calendaires. Si vous souhaitez exclure les week-ends, le guide d'installation explique comment ajuster ce paramètre. Cette option n'est pas activée par défaut.

Puis-je avoir des paliers différents — par exemple J-21, J-10, J-1 ? +

La version 1 utilise les paliers fixes J-14, J-7, J-3. Des paliers personnalisables sont prévus dans une version ultérieure. Le code source vous appartient — vous pouvez adapter les valeurs si vous avez des connaissances techniques.

Que se passe-t-il si j'ajoute une nouvelle deadline au tableur ? +

Elle est prise en compte dès le lendemain matin au moment du contrôle quotidien. Pas besoin de redémarrer le système ou d'intervenir.

Je travaille avec plusieurs personnes. Le système peut alerter chacun ? +

En version 1, les alertes vont sur une seule messagerie instantanée (la vôtre). L'envoi multi-destinataires par projet est une piste pour la version 2.

C'est vraiment sans abonnement ? +

Oui. Vous payez 39 € une fois, vous gardez le système. Aucune carte n'est débitée ensuite. Aucune relance commerciale.
