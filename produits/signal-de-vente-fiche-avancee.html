Questions fréquentes

Dix questions. Dix réponses franches.

1. C'est vraiment sans abonnement — définitivement ? +

Oui, définitivement. Vous payez 9€ une fois et vous gardez le système pour toujours. Aucune carte n'est débitée à nouveau. Aucune relance. Aucun palier « premium » caché. C'est une décision structurante de l'atelier (ADR-014) : L'établ'IA ne vend qu'en paiement unique.

2. Quelle plateforme e-commerce est supportée ? +

Le système fonctionne avec toute plateforme e-commerce disposant d'un mécanisme de webhooks ou d'un connecteur API (les plus populaires en France le proposent). La notice d'installation détaille les versions supportées. Si vous doutez de la compatibilité avec votre boutique, écrivez-nous avant d'acheter — on vous répond sous 48h.

3. Quelle application de messagerie reçoit les alertes ? +

Le système supporte nativement les applications de messagerie instantanée disposant d'une API bot (la plupart des messageries populaires en France). Un adaptateur alternatif (email + messagerie d'équipe) est inclus dans la boîte. Si vous avez une préférence, contactez-nous — on peut vous orienter vers l'adaptateur le mieux adapté à votre usage.

4. Je ne suis pas développeur. Est-ce que je vais y arriver ? +

Si vous savez naviguer dans une interface web et copier-coller du texte, c'est fait pour vous. La notice est écrite pour quelqu'un qui n'a jamais ouvert un outil d'automatisation. Chaque étape est illustrée d'une capture d'écran. Temps médian constaté lors des tests : 22 minutes. Si ça ne passe pas seul, on propose l'installation accompagnée pour 15€ de plus.

5. Le journal automatique — qu'est-ce que ça contient exactement ? +

À chaque commande, une ligne est ajoutée automatiquement à votre tableur (horodatage, numéro de commande, montant, nombre d'articles, statut de paiement). Vous obtenez un historique chronologique propre, exportable en CSV pour votre comptabilité. Aucune action manuelle requise. Le tableau est partageable avec votre comptable si vous lui donnez l'accès.

6. Que se passe-t-il si ma plateforme e-commerce change d'API ? +

Le code source est entièrement à vous — vous pouvez l'adapter. Si un changement majeur d'API intervient dans les 12 mois suivant votre achat, nous fournissons gratuitement un adaptateur mis à jour (inclus dans l'abonnement aux mises à jour 12 mois). Au-delà, les mises à jour critiques de sécurité restent gratuites.

7. Est-ce que mes données de commande quittent ma boutique ? +

Le système fonctionne sur votre propre compte de moteur d'automatisation — vous contrôlez toutes les connexions. Aucune donnée ne transite par les serveurs de L'établ'IA. Les données vont de votre boutique vers votre messagerie et votre tableur, uniquement. Le code source est lisible : vous voyez exactement ce qui est transmis.

8. Le bundle 3 systèmes — comment je choisis les deux autres ? +

Vous composez votre bundle librement depuis le catalogue. La remise de 20% s'applique automatiquement sur la somme des trois prix. Envoyez votre sélection via le formulaire de contact, on vous envoie le lien de paiement groupé sous 24h. Si vous ne savez pas quoi choisir, le diagnostic gratuit vous recommande les 3 systèmes les plus adaptés à votre activité.

9. Et si je ne suis pas satisfait après installation ? +

30 jours de garantie remboursement, sans condition. Si le système ne fait pas ce qui est annoncé sur cette page, on rembourse intégralement. Notre approche : on essaie d'abord de corriger ("Satisfait ou Forgé") — si la correction n'aboutit pas en 5 jours ouvrés, remboursement immédiat. Aucune question, aucune procédure.

10. Ce système a-t-il été conçu avec de l'intelligence artificielle ? +

Oui — et nous ne le cachons pas (position D11 / ADR-010). Le système forgé a été conçu et testé avec l'assistance d'outils IA, sous la direction et validation de Raphaël, artisan de l'atelier. La notice, les modèles de message et la documentation sont écrits et relus humainement. Si vous avez une question sur notre méthode, la page L'atelier l'explique en détail.
