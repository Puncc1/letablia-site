Le problème que vous connaissez

Des heures oubliées. Une facture sous-estimée.

Fin de mission. Vous essayez de reconstituer la semaine depuis vos notes, vos emails, vos souvenirs. Vingt minutes perdues — et une facture que vous sous-estimez quand même.

Les freelances et consultants sous-facturent en moyenne entre dix et quinze pour cent de leur temps. Non par générosité — par manque de trace. L'heure saisie immédiatement vaut dix fois l'heure reconstituée.

Ce que le système forgé fait
  • ✓Reçoit vos saisies horaires par messagerie en quelques secondes
  • ✓Parse automatiquement le projet, la durée et la description
  • ✓Calcule le montant facturable selon le taux configuré par projet
  • ✓Confirme immédiatement la saisie avec le montant calculé
  • ✓Enregistre chaque ligne dans un tableur structuré, prêt à facturer

Pas d'application à ouvrir. Pas de connexion séparée. Votre messagerie est déjà ouverte.

Comment ça marche

Quatre étapes. Moins de 20 minutes.

01

Vous configurez vos projets

Renseignez chaque projet dans le tableur : code court, nom complet, taux horaire. Un taux par défaut s'applique si un projet n'est pas configuré.

02

Vous branchez

Messagerie instantanée et tableur. Deux connexions. Le guide d'installation les couvre intégralement, étape par étape.

03

Vous saisissez en cours de journée

Un message court : projet-a 1h30 réunion. Confirmation immédiate avec le montant calculé.

04

Votre tableur est prêt à facturer

En fin de mois, toutes les lignes sont là : date, projet, durée, description, montant. Aucun retraitement manuel.

Pour qui

Fait pour les freelances et consultants à facturation horaire qui oublient des heures chaque mois.

Ce système convient si vous êtes :

  • ✓Freelance, consultant ou collaborateur en agence à facturation horaire
  • ✓Vous avez entre 5 et 50 projets actifs par mois
  • ✓Vous avez déjà raté des heures facturables par friction de saisie
  • ✓Votre messagerie est ouverte en permanence sur votre poste

Ce que ce système ne fait pas :

  • —Il ne génère pas la facture PDF
  • —Il ne se connecte pas à un logiciel de facturation externe
  • —Il ne gère pas les notes de frais ni les déplacements
  • —En version 1, il ne gère qu'un seul utilisateur à la fois
Questions fréquentes

Avant d'acheter.

Peut-on saisir en minutes plutôt qu'en heures ? +

Oui. Le format projet-a 45min fonctionne. Le guide des commandes fourni dans le ZIP liste tous les formats acceptés : heures entières, fractions, minutes.

Que se passe-t-il si je fais une erreur de saisie ? +

Si le format est incorrect, le système vous le signale immédiatement et vous rappelle la syntaxe attendue. Si vous avez validé une saisie erronée, la correction se fait manuellement dans le tableur — une suppression de ligne.

Peut-on utiliser le même système pour plusieurs projets avec des taux différents ? +

Oui. Vous configurez autant de projets que nécessaire dans la feuille de configuration du tableur, chacun avec son propre taux horaire. Un taux par défaut est également configurable pour les projets non listés.

Est-ce compatible avec ma messagerie instantanée actuelle ? +

Le guide d'installation couvre la connexion aux messageries instantanées courantes accessibles via API ou webhook. Consultez la liste des adaptateurs fournis avant l'achat pour vérifier la compatibilité avec votre outil.

C'est vraiment sans abonnement ? +

Oui. Vous payez 29 € une fois, vous gardez le système. Le code source vous appartient. Aucune carte n'est débitée ensuite. Aucune relance commerciale.
